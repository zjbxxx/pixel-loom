# 像素置乱器 · Pixel Loom

把像素搅成噪声，而且随时能逐像素还原。一个纯前端、零依赖的单文件图像置乱工具。

- **在线访问**：<https://pixel-loom.app.workbuddy.host/?sharecode=4S3VJ6EXN5>
- **本地运行**：直接用浏览器打开 `pixel-loom.html`，无需安装、无需构建、无需联网

---

## 它是什么

Pixel Loom 对图片做一次**严格可逆**的像素级置乱：处理后的图片在人眼里就是一片噪声，看不到任何原图轮廓；但只要拿到密钥，就能一个字节不差地还原回原图。

与常见的「马赛克 / 模糊 / 局部涂抹」不同，它不是遮盖，而是**双射变换**——信息没有丢失，只是被重排了。

## 功能

| 能力 | 说明 |
| --- | --- |
| 加密（置乱） | 拖入图片 → 调节强度 → 生成噪声图，输出无损 PNG |
| 还原 | 拖入置乱图，自动读取内嵌密钥并逐像素复原 |
| 打乱强度 | 1%–100% 可调，实时显示预计被改写的像素比例 |
| 口令保护 | 可选设置口令，用 PBKDF2 派生密钥；留空则使用一次性随机密钥 |
| 密钥备份 | 生成为 `eyJ...` 开头的密钥串，可复制另存，便于图片被压缩/截图后手动还原 |
| 可逆性自检 | 生成后自动校验解密结果是否与原图逐字节一致 |
| 结果统计 | 展示改写像素比例等对比数据 |
| 便捷输入 | 支持拖拽、点击选择、`⌘V` 直接粘贴图片 |
| 输入格式 | JPG / PNG / WebP / GIF / BMP，统一输出无损 PNG |

## 使用方法

1. 打开页面，默认在「加密」标签页
2. 拖入或粘贴一张图片
3. 按需拖动「打乱强度」滑块（默认 100%）
4. 如需保密，填写口令；否则密钥会写进图片元数据，任何人都能还原
5. 点击「生成置乱图」→「下载 PNG」
6. 还原时切到「还原」标签页，拖入置乱图 → 点击「开始还原」

**务必保留 PNG 原文件。** 置乱图一旦被截图、微信压缩、转存为 JPG，元数据就会丢失，此时需要手动粘贴加密时备份的密钥串才能还原。

## 原理

核心是两步互逆变换，两步都是「一一对应」，因此整体严格可逆。

```
    原图  ──① 位置置换──▶  ──② 逐像素异或──▶  噪声图
                                                    
    原图  ◀──① 逆向置换──  ◀──② 逐像素异或──  噪声图   （执行顺序相反）
```

1. **位置置换（Permutation）**
   用密钥派生的伪随机流做 3 轮随机交换，把每个像素搬到毫不相干的位置，彻底破坏空间结构。

2. **值置换（Keystream XOR）**
   每个像素的 R/G/B/A 再与密钥流派生的随机字节逐位异或，摧毁颜色分布、直方图与边缘统计。

3. **可逆性**
   交换的逆运算就是交换本身，异或的逆运算就是异或本身。加密与解密复用同一条密钥流，只是执行顺序相反。

### 关于「打乱强度」

强度决定有多少像素参与置换，参与密度取强度的平方：

- **低强度**：只有少量像素「搬家」，画面局部破碎但轮廓仍在，适合想要可见效果的场景
- **高强度**：几乎每个像素都参与，整幅图变成均匀噪声

关键设计：参与搬家的像素不限于相邻位置，它可以与**全图任意位置**的像素交换颜色。因此即使强度不满 100%，也**不存在成块原样保留的像素**——早期版本正是因为在低强度下留有成片未动像素，眼睛才能把它们拼回模糊的原图。

### 密钥派生

```
口令（可为空） + 随机盐
      │
      ▼  PBKDF2-HMAC-SHA256，20 万次迭代
      │
   32 字节主密钥  ──▶  派生出置换序列与异或密钥流
```

- 设置口令：密钥不随图保存，**没有口令无法还原**
- 留空口令：使用一次性随机密钥，并写入图片 PNG `tEXt` 元数据块，图片自身即可还原

### 为什么输出必须是 PNG

JPG 是有损压缩，重新编码会改动密文的比特位，导致还原永久失配。本工具自行编码 PNG（8bit RGBA + 非压缩数据块），主动绕开浏览器 canvas 对半透明像素的预乘舍入误差，保证像素字节完全无损。

## 安全边界（重要）

- ✅ 能防「随手看一眼」：任何人看到的都只是噪声
- ✅ 设了口令后，没有口令连统计分析都无从下手
- ⚠️ **这不是经过密码学审计的加密方案**，请勿用于真正机密的资料
- ⚠️ 原图的 EXIF、ICC 等元数据在重新编码时会丢失，只有像素被完整保留
- ⚠️ 丢失密钥串、且置乱图元数据被破坏 → 无法还原

## 技术栈

- 单文件 HTML，内联 CSS + 原生 JavaScript，**零外部依赖、零构建步骤**
- 自带 SHA-256 / HMAC / PBKDF2 的纯 JS 实现
- 自带 PNG 编解码器（tEXt 元数据读写、CRC32 / Adler32、zlib store 模式）
- 全部计算在浏览器本地完成，**图片不会上传到任何服务器**
